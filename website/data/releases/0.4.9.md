- New! A user node can combine accounts with `|` and `&`, e.g. `accounts = (carryover | annual) & valley_cap`. See [combining accounts](https://kalix.org/docs/accounts/#combining-accounts).
- New! RAS `distribute(x, by_size)` and `distribute(x, by_balance)` share one volume across a group of accounts. A full or empty account passes its share to the others. See [RAS](https://kalix.org/docs/ras/#distribute).
- New! Plot on a second Y axis (#196):
    - Ctrl+click a series in the key (Cmd+click on macOS), or right-click it and choose `Move to right Y axis`.
    - Each axis has its own menu when you right-click the plot: `X axis`, `Y axis (left)` and `Y axis (right)`, with `Fit to data`, `Set range…`, `Copy range`, `Paste range` and `Auto-range` (#505).
    - Drag an axis to change its range. Double-click a Y axis to fit it to the data in view, or the time axis to see the whole record.
- New! Tabular view for plotted. The `Data` view sits beside `Plot` and `Stats` in each plot tab.
- New! "Regions" let you collapse parts of the model in the text editor (`#@region = Title`). Sections and multi-line values are also collapsable. See `Fold` and `Unfold` on the Edit menu.
- Stricter model checks. **Breaking:** models that break these rules are now refused when the engine loads them (#442, #479):
    - Node names may contain only letters, digits and underscores. Names that differ only in case are duplicates.
    - A section header, a key, or a `[data]` entry may appear only once. An entry listed twice in `[outputs]` is recorded once.
    - An expression or `[outputs]` entry that refers to a node, output, var or constant that doesn't exist is an error. It used to read 0.
    - An input CSV needs at least two rows, and all inputs must share one timestep.
    - A `start` after the `end`, or outside the input data, is refused with both dates named.
    - The IDE's linter flags all of these before you run.
- IDE:
    - Files dragged from Finder or Explorer onto the project tree are copied into the folder they land on (#469).
    - The key grows to fit a long series name, and shows a cut name as a tooltip (#508).
    - Editors in the optimiser window now follow the dark themes (#509).
    - Unticked series are freed from memory.
    - A burst of plot requests no longer stalls the Run Manager for a minute.
    - `Save Data` on a double-mass plot writes the cumulative reference as the first column, not dates in 1970.
- Python package:
    - `read_pixie()` returns an empty series as a column of NaN.
    - `set_input()` raises `ModelValidationError` for data with fewer than two rows.
- Dev:
    - Kalix IDE is now built on Java 25 (LTS).
    - **Breaking:** Python 3.11 or newer is now required. Support for 3.9 and 3.10 has been dropped.
