- Changed: the [Run Manager's Timeseries filter](https://kalix.org/docs/ide/#filtering-the-timeseries-tree) now matches the full series name (`inflow_3.ds_1` works), and accepts wildcards (`inflow_*.ds_1`), regular expressions (`/…/`) and exclusions (`!dummy`). Several space-separated terms must all match, and a term also matches the run or file name. Text that doesn't parse turns the box red and keeps the last filter that worked.
- New! [Derived series](https://kalix.org/docs/ide/#derived-series) in the Run Manager: the point-by-point sum of series from a run, the Last run, or a loaded dataset. Filter and tick (or select) series in the Timeseries tree, then right-click and choose `Sum checked…` (or `Sum selected…`).
    - Series from several runs make one derived series per run, so totals can be compared across runs; a folder sums everything under it as the filter shows it.
    - Derived series of the Last run are recomputed when a new run completes.
    - Derived series can be renamed, deleted, and saved as CSV, zipped CSV or Pixie from the source tree.
