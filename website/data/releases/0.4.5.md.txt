- One comment grammar for model files: `#` starts a comment anywhere, section headers included.
- Routing `pwl` tables now accept a header row, like every other node table.
- CSV export writes the shortest exact number spelling, switching to exponent form only for extreme values.
- Automatic data masking: selecting a plot type now applies that type's default overlapping-data mask, indicated by badges in the plot-type dropdown.
- Plot tab `Reset` now works in place: the tab's name, position and undo history survive, and the reset itself is a single undoable step.
- Plot undo/redo now restores the complete view: checked sources come back alongside the series, and ticking/unticking a source is an undoable step in its own right.
- Run & data tree tick-boxes now stay in sync with the plot through tab reset, undo/redo, and tab duplication.
- `[Last]` self-heals: deleting the newest run re-points `[Last]` plots to the most recently completed surviving run, or waits (still subscribed) for the next run to arrive.
- Fixed: unloading a dataset left a do-nothing undo step; a duplicated tab could show a stale mask toggle; re-selecting the current plot type discarded a manual mask override and reset the zoom.
- Table View no longer goes stale after the optimiser rewrites the model.
- Editor hover tips now go through Swing's tooltip manager, fixing stale property help and dismiss delays.
