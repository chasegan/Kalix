- New! Accounts can have a `debit_factor`, so a user's take of 1 ML debits more (or less) than 1 ML. See [debit factor](https://kalix.org/docs/accounts/#debit-factor).
- New! A storage can order to a `target_volume` as an alternative to `target_level`, and `forecast_volume_adjustment` lets you allow for water you expect to arrive or leave. See [storage](https://kalix.org/docs/storage/).
- New! `[var.*]` blocks can run in the order phase with `phase = order`. See [vars](https://kalix.org/docs/vars/).
- New! Gzipped CSV files (`.csv.gz`) work wherever `.csv.zip` does. See [compressed CSV files](https://kalix.org/docs/input-data/#compressed-csv-files-csvzip-csvgz).
- Smoother map and plot navigation in the IDE:
    - Shift+scroll pans, and trackpad zoom is smooth.
    - Ctrl+0 (Cmd+0 on macOS) zooms the map to fit.
    - `View → Scroll Pans Map` makes scrolling pan the map.
- IDE:
    - `Gzip` and `Gunzip` in the file tree.
    - `Zip` is more robust, and `Duplicate` keeps the whole extension (`flows (1).csv.zip`).
    - Alt+letter opens the menus on Windows and Linux.
- Fixes:
    - `true` and `false` are read in any case (#522).
    - `kalix simulate` exits with an error when it cannot write its output.
    - An account can no longer be called `debit_factor`.
