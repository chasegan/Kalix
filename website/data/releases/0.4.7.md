- New! [`field` node type](https://kalix.org/docs/field/) for crop modelling
- New! Regulated and unregulated user nodes now accept links on ds_2, ds_3, and ds_4. Nodes or entire sub-networks can attach here, turning the user node into a conduit for accessing river flows.
- Improved: [reach losses on routing nodes](https://kalix.org/docs/routing/#reach-losses-and-dead-storage) now use a `dimensions` table to define dead storage and reach surface area.
    - Dead storage fills before the reach flows, and drains by evaporation while it doesn't.
- New! [Derived series](https://kalix.org/docs/ide/#derived-series) in the Run Manager: the per-timestep sum across multiple series.
    - To use this, select multiple series and then right-click and choose `Sum checked…` (or `Sum selected…`).
    - Derived series of the Last run are recomputed when a new run finishes.
- New! Error log accessible on the left-hand side of the status bar once an error has occurred.
    - Click it to open the log as a tab.
- New! [`gr4jsg` node type](https://kalix.org/docs/gr4jsg/) adds snow and glacier melt simulation to the base GR4J model.
- New! Bilinear interpolation on 2D tables.
    - Use `bilinear = true` on a 2D table to interpolate across both axes.
