Capabilities

What Kalix does.

Plain-text models

INI files you can diff, review and version in Git — editable by hand or in the IDE.

Visual network editor

See the whole catchment as a node graph and edit the schematic and text side by side.

Commandline & Python

Run headless in CI, batch scenarios, or drive Kalix from a notebook via Python bindings.

Optimisation built in

Calibrate with SCE, CMA-ES, Differential Evolution and DREAM against your objective functions.

Rainfall-runoff models

Proven conceptual models including GR4J and Sacramento, ready to wire into any node.

Fast Rust core

Century-long daily simulations over hundreds of nodes, run in seconds.

Free and open-source.

Kalix is released under the MPL 2.0. Install it from PyPI, or download the IDE for macOS, Windows and Linux. Use it if it's useful to you.
