- Confluence `regualted` branch property: `regulated = <comma separated node(s)>` names the upstream regulated pathways. Specifying a single branch sends all orders there, while specifying two invokes `harmony_fraction` to determine the fraction of orders sent to the first branch. See [confluence](https://kalixproject.org/docs/confluence/).
- New calendar functions: `is_leap_year(y)`, `month_at(n)`, `days_in_month_at(n)` and simulation variables `sim.days_in_month`, `sim.days_in_year`, `sim.is_leap`. See [expressions](https://kalixproject.org/docs/dynamic-expressions/).
- New account `pair` concept for modelling carryover, plus per-target `self` in RAS action arguments (`self.balance`, `self.size`, `self.allocation`, `self.pair.*`). Carryover actions can be like: `set(0.9 * self.pair.balance)`. See [accounts](https://kalixproject.org/docs/accounts/) and [`[ras.*]`](https://kalixproject.org/docs/ras/).
- Vars in ras phase: `[var.*]` blocks with `phase = ras` run in the ras phase interleaved with the `[ras.*]` sections, allowing designs such as daily evaluation and then `allocate(var.assessment.aa)` as required. See [vars](https://kalixproject.org/docs/vars/).
- Use `this` in a var defintion to refer to the var's own series, e.g. `my_var = this[-1,0] + 1`. See [vars](https://kalixproject.org/docs/vars/).
- New account and group results: `acc.<name>.use` (water taken since the last reset). Group aggregates for `size` and `use`, with `size` readable everywhere including announce-time assessments. `ras.<name>.fired` and `.pct` are now readable in expressions too. See [accounts](https://kalixproject.org/docs/accounts/).
- Routing `pwl` extrapolation now uses flat extrapolation (constant final value) for mass-balance safety. Tables no longer need a huge-flow guard. See [routing](https://kalixproject.org/docs/routing/).
- Pixie format input data: `[data]` now accepts Pixie files as model inputs. Pixie is smaller and faster than CSV. KalixIDE offers `.pxt` files in `[data]` autocomplete and checks for the named `.pxb` companion. See [`[data]`](https://kalixproject.org/docs/input-data/).
