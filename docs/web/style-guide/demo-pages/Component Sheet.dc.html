06

Callouts & admonitions

i

Note

Node ordering is derived automatically from the connection graph.

✓

Tip

Use relative paths from the trailhead so models stay portable across machines.

!

Warning

Changing the simulation step size invalidates the cached results.

×

Danger

A blackhole node silently discards all upstream flow. Verify before running.

08

Screenshot framing

GUI captures carry the product. Frame them with a hairline border, soft elevation, a corner zoom affordance, and a mono caption — no added window chrome, since Kalix captures already include the OS frame.
