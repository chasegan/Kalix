- STATEFUL PYTHON API: a native `Model` class — load, inspect, edit and run models entirely in memory, with results and mass balance returned as DataFrames. See [Python](https://kalixproject.org/docs/python/).
- New RAS actions `credit_fraction(x)` and `roll_cap(n)` — the latter gives a rolling n-water-year usage cap. See [`[ras.*]`](https://kalixproject.org/docs/ras/).
- New `opportunistic_demand` on regulated user nodes. See [regulated user](https://kalixproject.org/docs/regulated-user/).
- GUI stuff: live search and counter in Find; node labels can be toggled off/on in the map.
