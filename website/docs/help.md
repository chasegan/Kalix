# Help

<p class="kx-help-lead">Ask a question and the assistant answers from the Kalix documentation, with links to the pages it drew on. It knows the docs, tutorials, and developer guide; it does not know your model. For anything it cannot answer, or to talk to a person, use <a href="https://github.com/chasegan/Kalix/discussions">GitHub Discussions</a>.</p>
