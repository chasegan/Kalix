Code

Kalix is open source under the MPL 2.0. The engine is Rust, the IDE is Java, and the Python package wraps the Rust core — all developed in the open on GitHub.

MPL 2.0 Rust · Java · Python github.com/chasegan/Kalix ↗

Ways to get involved

◇
Report a bug or request a feature
Everything is tracked openly on GitHub Issues — so you can see what's happening at all times.
 ⑂
Build from source
Fork, clone and compile your own Kalix. The licence lets you use and modify the code freely.
 ⧉
Collaborate on dev
Organisations can run a remote team on a shared fork; individuals can join the core team and work directly in the repository. Either way, we'd love to work together — get in touch.

Build from source

terminal
# engine (Rust)
git clone [email protected]:you/Kalix.git
cargo build --release
# IDE (Java)
./gradlew :kalixide:run
Rs
Rust via rustup — cargo
Jv
JDK 23 (Temurin) — gradlew
Py
Python 3.12+ — maturin

Recommended editors: RustRover for the engine, IntelliJ IDEA CE for the IDE. CI runs the full suite on Linux, macOS and Windows via GitHub Actions.
